Installer Dikkenek Play sur un Mac

Aucun message d'alerte, rien d'autre à installer. Mac Apple Silicon (M1 ou plus récent), macOS 12+.

1
Cliquez sur le bouton pour copier la commande d'installation :
curl -fsSL https://raw.githubusercontent.com/renaud-bxl/dikkenek-play/main/install.sh | bash
2
Ouvrez l'application Terminal : touche ⌘ + Espace, tapez Terminal, Entrée.
3
Collez la commande (⌘ + V) et appuyez sur Entrée. Le téléchargement (≈ 220 Mo) démarre, l'application s'installe dans Applications et s'ouvre toute seule.

La même commande sert aussi pour les mises à jour : elle installe toujours la dernière version. Le mode d'emploi (LISEZ-MOI) est déposé sur le Bureau à l'installation.
Logiciel créé par Renaud Ben Lakhal pour l'événement DIKKENEK 20 ANS.
